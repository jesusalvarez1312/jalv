Neue Karte anlegen

Trag die Angaben ein. Unten entsteht die fertige Zeile, die du in deine Datei kopierst.

  1. Zeile kopieren.
  2. Auf GitHub die Datei index.html öffnen und auf den Stift klicken.
  3. Nach MEIN_LEBEN suchen (Strg+F).
  4. Die Zeile unter die vorhandene setzen — auf das Komma am Zeilenende achten.
  5. Unten auf „Commit changes" klicken. Fertig.
